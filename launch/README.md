# Double-click one of these

| You are on | Double-click |
|---|---|
| Windows | `crossfoot.bat` |
| macOS | `crossfoot.command` |
| Linux | `crossfoot.sh` |

The first run installs what it needs into a `.venv` folder beside this one and
takes about a minute. Every run after that just opens the window.

You still need Python installed. If you do not have it, the script says so and
points you at python.org — on Windows, tick **Add Python to PATH** during the
install.

These are ordinary text files you can open and read before running them, which
is on purpose. Crossfoot reads your bank statements; a script you can inspect
in Notepad is a better thing to trust than a downloaded binary, and it is why
there is no `.exe` here.
